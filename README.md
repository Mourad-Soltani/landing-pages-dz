# لاندِكس (Landix) — صفحات هبوط تبيع

صفحة هبوط عربية عالية التحويل لخدمة **تصميم صفحات الهبوط** للبائعين، الفريلانسر، والشركات في **الجزائر والخليج**.

## عن الخدمة

**لاندِكس** تصمم صفحات هبوط سريعة ومقنعة ومربوطة بالواتساب والدفع:

- للبائعين (منتج واحد)
- للفريلانسر (معرض أعمال + حجز)
- للشركات (ليدز مؤهلة + CRM)

### المميزات الرئيسية

- تسليم خلال **72 ساعة**
- سرعة تحميل &lt; 2 ثانية
- ربط واتساب + Pixel (فيسبوك / تيك توك)
- دفع جزائري: **BaridiMob / CCP** + الدفع عند الاستلام
- للخليج: تاب / مدى / STC Pay
- بدون اشتراك شهري — دفع مرة واحدة
- استضافة ودومين مجاني أول سنة

### الباقات

| الباقة | السعر | لمن |
|--------|-------|-----|
| **Starter** | 8,000 دج | للبائعين |
| **Pro** | 15,000 دج | للفريلانسر (الأكثر طلباً) |
| **Business** | 28,000 دج | للشركات |

## التقنيات

- React 18 (ملف HTML واحد)
- Tailwind CSS
- خطوط Tajawal + Cairo
- تصميم داكن (Dark UI) مع تدرجات بنفسجي/برتقالي

## Live visitor counter

عداد زيارات مباشر في أعلى الصفحة (يسار):

- API: [countapi.mileshilliard.com](https://countapi.mileshilliard.com)
- المفتاح: `landing-pages-dz-visits`

عرض القيمة الحالية:

```
https://countapi.mileshilliard.com/api/v1/get/landing-pages-dz-visits
```

3. غيّر رقم الواتساب والرسائل حسب حاجتك
